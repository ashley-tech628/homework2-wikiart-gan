# Earlier experiments and drafts

This directory preserves prior work without mixing it into the final full-data presentation.

- [`legacy_64px/`](legacy_64px/) contains the initial 2,390-image trials, code, notebooks, metrics, and small checkpoints. These runs used different data and evaluation protocols from the final report.
- [`notebooks/`](notebooks/) holds the later Kaggle full-data notebook. The final recorded full-data results used in the report came from DataHub.
- [`previous_report/`](previous_report/) holds the superseded ReportLab report generator and its chart. The submitted report is [`../report/homework2_wikiart_report.pdf`](../report/homework2_wikiart_report.pdf), generated from [`../latex/main.tex`](../latex/main.tex).

The archive is retained for provenance. The repository overview, `results/`, and report focus on the completed full-data experiments.
